Connect and install the preview

  1. Check Google’s current custom-app requirements. Feature availability is controlled by Google and can depend on your account, location, settings, and Gemini surface.
  2. In Gemini, add UCE Evidence Lens under custom connected apps using this shared MCP endpoint: https://uce-evidence-lens-claude-zptt2ggs7a-uc.a.run.app/mcp
  3. Confirm that Gemini shows exactly inspect_uce_record and get_uce_inspection_report. The endpoint requires no UCE sign-in, API key, or OAuth credentials.
  4. Download inspect-uce-evidence.zip, then upload it through Gemini’s Skills settings and confirm inspect-uce-evidence is active. Use the release ZIP, not GitHub’s automatically generated source archive.

Connecting the custom app and uploading the skill are separate steps. This is public direct-install preview 0.1.0-preview.1. There is no Google app-catalog listing or submission. The existing endpoint is shared with another Lens integration, so its hostname retains claude; this does not change what Lens checks or where the server performs its checks.

Common questions

No custom-app or skill setting appears. What can I do?
Check Google’s current eligibility and rollout requirements. The package cannot enable Google features that are unavailable to your account.
The skill is installed, but the tools are missing. Why?
Connect the MCP app separately. In the tested account, tools appeared in Spark’s @ picker. An installed skill does not create the connector connection.
Why am I asked for OAuth or an API key?
Check the exact endpoint. This service requires neither. Stop and contact Lens support if the request persists.
What should I do after a blank or failed turn?
Refresh once, then make one explicit retry with the same public reference. Stop if it remains blank. Use the browser-based Evidence Lens or contact support. A missing response says nothing about whether a record passes or fails a check.
Why is a check unavailable, partial, or unsupported?
Review each check and its stated coverage. A public source can be pending, rate limited, unavailable, or too slow. The connector does not infer support for unknown record versions or hybrid profiles. These statuses are not verification passes, and an outage is not evidence of tampering.
What if the reference is rejected?
Use a public CbyUCE verification link or 64-character record hash, or an Arweave manifest transaction link or 43-character ID. Private links, arbitrary websites, pasted manifests, and files are outside the tools’ accepted inputs.
Why does a source link open Google Search?
Ask Gemini to return the exact URL as copyable text. Corrected direct-link rendering remains unverified in this preview.
What if there is no report attachment?
Native file download is unverified. Use the conversation’s report results or the browser Lens. If Gemini supplies complete report JSON, you may save it yourself; do not treat a prose summary as the complete JSON report.
How do I compare my original file?
Use the separate browser-based Evidence Lens and its private local-file comparison. The Gemini connector never retrieves or hashes your local original.
Does a verified result prove ownership?
No. Review exactly which integrity or chronology check passed and what it covers. Identity, authorship, ownership, rights, consent, provenance, and creation-date statements remain recorded assertions.

Tested surface

In one personal account on the Gemini web app, both tools succeeded in native Spark, each after one retry. Spark also produced blank or failed turns, including for a simple control request that used no tools; the cause was not established. Native file downloads, corrected direct links, ordinary-chat tool availability, and mobile workflows remain unverified.
