UCE Evidence Lens for Gemini

Inspect an explicitly identified public Universal Creation Evidence record in Gemini. Understand the checks, explore their limits, and request an unsigned inspection report.

Set up in GeminiDownload the skill ZIP

A public direct-install preview. Connect the UCE app and upload the skill separately. Our tested workflow uses Gemini Spark on the web. Google controls account, region, subscription, and rollout eligibility. This release has not been submitted to or listed in a Google app catalog.

Inspect a public record

inspect_uce_record retrieves an approved public record and returns separate format, covered manifest-hash, platform-signature, chronology, assertion, and coverage results.

Create a dated report

get_uce_inspection_report performs a fresh inspection and returns an unsigned JSON snapshot bound to that same explicit record. Native downloadable report attachments remain unverified.

What a result means

Checks run on the UCE server using the reviewed Lens verifier. The skill helps Gemini interpret the returned results; it is not a verifier on its own.

Evidence integrity does not establish the truth of identity, authorship, ownership, rights, consent, provenance, or creation-date assertions recorded in a manifest. Parsing, covered manifest hashing, signature validity, chronology, publisher reports, and recorded assertions remain separate.

An unsigned dated report is not a UCE Certificate or a new permanent record. Lens does not register copyright, provide legal advice, guarantee legal protection, prevent infringement, enforce DRM, or imply endorsement by Google, Anthropic, or OpenAI.

Connect the app and add the skill

Check access before installing. Google's custom connected apps currently require a personal Google Account, age 18+, US location, English, and Keep Activity enabled. Spark may require a Google subscription. Review Google's current requirements, your privacy choices, and the Lens privacy policy and terms.

  1. In the Gemini web app, open Settings → Connected Apps, sometimes under Personal Intelligence. Under Custom apps or Custom apps for Spark, add this MCP server:https://uce-evidence-lens-claude-zptt2ggs7a-uc.a.run.app/mcp
  2. Review the connection and confirm both tools: inspect_uce_record and get_uce_inspection_report. No UCE sign-in, API key, OAuth credentials, or payment is required. If your account requests credentials for this endpoint, stop and contact support.
  3. Download inspect-uce-evidence.zip. In Settings → Skills → Upload, select the ZIP, review it, and create inspect-uce-evidence. Confirm the skill is active.
  4. Start a Spark task. Select UCE Evidence Lens with @ and inspect-uce-evidence with /. Supply an explicit public record reference using the example below.

The service is shared with our Claude integration, so its hostname retains claude. The same read-only tools serve Gemini. Installing the skill does not connect the app automatically.

The four-file skill contains instructions, evidence boundaries, and license notices. Download that skill ZIP, not GitHub's automatically generated source-code archive. See the skill source, download checksum, and Google's skill instructions.

Only share public record references. Do not send unpublished works, private files or manifests, credentials, payment information, or sensitive information.

Start with an explicit public record

For example:

Inspect public UCE record d16afbafda0ef0bf1be29d4f89e8629fc2aa0eae55da30103aeb5e6a59abd9a5 and explain each check and what remains unsupported or incomplete.

Then request a report separately:

Create an unsigned inspection report for public UCE record d16afbafda0ef0bf1be29d4f89e8629fc2aa0eae55da30103aeb5e6a59abd9a5. Explain what completed and what remains unchecked. Include the exact returned public-record and Lens viewer URLs as direct links and copyable text.

Look for an actual UCE tool action and returned check results. A task title or an empty answer is not an inspection. Partial, unsupported, unavailable, reported, and retryable results stay explicit.

What we have tested

In our October 3, 2026 Gemini web test, the account-free connector exposed both tools. Native Spark inspection and report calls succeeded, each after one retry. The revised skill asked for a missing reference in ordinary chat without selecting a record or calling a verification tool.

Spark also produced blank or failed turns, including on a simple no-tools control. The cause is not established. Native report downloads, corrected direct-link rendering, ordinary-chat tools, and mobile workflows remain unverified. A downloadable report attachment is not promised.

If a turn is blank, refresh once and make one explicit retry with the same public reference. If it is still blank, stop and contact support or use the Evidence Lens browser. A missing response does not mean the record failed a check.

See the versioned release notes for the tested scope.

Current coverage and limits

  • No original-work uploads, accounts, evidence creation, certificate issuance, payments, credit consumption, or event subscriptions.
  • No local-file retrieval, hashing, or comparison. That workflow remains in the Evidence Lens browser.
  • Retrieval is restricted to approved public sources. The service does not fetch arbitrary websites, and unknown versions do not silently receive a verification pass.
  • Reports preserve their explicit record, check time, coverage, and limitations. A prose summary is not the complete report JSON.

Update, remove, or get help

To update a skill, open it and choose Skill actions → Replace skill with the new release ZIP. Keep one active copy. To stop using it, deactivate or remove the skill and disconnect or remove UCE Evidence Lens in Connected Apps.
