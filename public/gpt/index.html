UCE Evidence Lens for ChatGPT

Inspect a public Universal Creation Evidence record and understand what its evidence supports. Ask for the checks, their limits, or an unsigned dated report.

How to use itOpen browser Lens

Preparing for public release. The integration is available for developer testing. It has not been approved or published in the ChatGPT directory, and there is no public installation link yet.

What Lens can check

  • Accept a supported CbyUCE or Arweave public record reference.
  • Separate format, covered manifest-hash, signature, and transaction-chronology checks.
  • Explain recorded assertions and show checks that remain incomplete or unsupported.
  • Produce an unsigned report tied to the record and the time of inspection.

What a result means

A valid signature or matching hash addresses a specific integrity check. It does not establish authorship, ownership, consent, rights, or the truth of a claimed creation date.

Lens does not create evidence, issue UCE Certificates, register copyright, enforce DRM, prevent infringement, or guarantee legal protection.

Start with a public record

  1. Enable the Lens connection in ChatGPT. During this preview, developer testers can follow the setup below.
  2. Provide one public CbyUCE verification link or record hash, or an Arweave manifest transaction link or ID.
  3. Ask what was verified, what remains unverified, and which results are publisher-reported.
  4. Ask for an inspection report for the same record. Review the included reference, check time, and limitations.

For example, using this public demonstration record:

Inspect https://cbyuce.com/verify/d16afbafda0ef0bf1be29d4f89e8629fc2aa0eae55da30103aeb5e6a59abd9a5 and explain what was and was not verified.

Only share public record references. Do not send unpublished works, private files, account credentials, or sensitive information.

Select no authentication for the Lens connection, then enable it in a new conversation. Follow the official ChatGPT connection instructions for the current interface and account requirements.

The Lens integration requires no separate Lens account and accepts no payment. ChatGPT access is governed by your OpenAI plan and workspace settings.

Current coverage and limitations

The reviewed verifier supports specified classical 1.0.0 and 1.1.0 checks. Coverage depends on the record profile; historical Standard hash nonmatches can remain unresolved. Hybrid 2.x verification and unknown formats are not claimed as supported.

Arweave rate limiting observed on September 30, 2026 affects direct Arweave retrieval and transaction-chronology checks from this preview service. Lens reports unavailable or retryable results instead of claiming a pass. A successful CbyUCE manifest check can coexist with incomplete chronology.

Checks run on the Lens server. For private local-file comparison, use the separate browser-based Lens workflow. The ChatGPT integration does not receive or compare original files.

Report downloads depend on the ChatGPT host. Where saving is unavailable, the widget provides the report as JSON text. A report is an unsigned dated snapshot, not a UCE Certificate or a new permanent record.

Know how your information is used

The integration receives the public reference in the tool call, retrieves approved public evidence, and returns its findings to ChatGPT. Read the privacy policy, terms of use, and support information before using it.
