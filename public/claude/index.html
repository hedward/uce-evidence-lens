UCE Evidence Lens for Claude

Inspect an explicitly identified public Universal Creation Evidence record and see what its evidence supports. Lens keeps integrity checks, chronology, recorded assertions, and coverage limits separate.

Connect the LensTry a public example

The Claude plugin is published. Anthropic’s security scan passed, and the plugin is published for Claude Code, Cowork, and Claude apps. Availability can vary by Claude plan, workspace, and listing propagation. As of October 3, 2026, the separate MCP connector’s directory listing is in review and is not live; eligible users can add the connector directly with the address below.

Inspect a public record

inspect_uce_record retrieves an approved public record and returns separate format, covered manifest-hash, platform-signature, chronology, assertion, and coverage results.

Create a dated report

get_uce_inspection_report performs a fresh inspection and returns an unsigned JSON snapshot bound to that same explicit record.

What a result means

A valid signature, matching covered hash, or chronology result addresses a specific check. Evidence integrity does not establish the truth of identity, authorship, ownership, rights, consent, provenance, or creation-date assertions recorded in a manifest.

Lens does not create evidence, issue UCE Certificates, register copyright, provide legal advice, enforce DRM, prevent infringement, guarantee legal protection, or imply endorsement by Anthropic or OpenAI. An unsigned dated report is not a UCE Certificate or a new permanent record.

Connect the Lens

  1. Install the plugin through an option available to your Claude plan or workspace. The public plugin repository contains the manual-install source and instructions.
  2. Open the plugin’s connector settings and connect UCE Evidence Lens. No UCE account, sign-in, API key, or payment is required.
  3. If your Claude workspace supports custom remote connectors, add this MCP server directly: https://uce-evidence-lens-claude-zptt2ggs7a-uc.a.run.app/mcp
  4. Confirm that Claude shows inspect_uce_record and get_uce_inspection_report.

Only share public record references. Do not send unpublished works, private files or manifests, credentials, payment information, or sensitive information.

Current coverage and limits

  • The connector performs bounded server checks. It does not retrieve, hash, or compare an original file. Use the separate browser-based Lens workflow for private local-file comparison.
  • Retrieval is restricted to approved public CbyUCE, Arweave, transaction-derived Arweave, and Turbo Gateway paths. The service does not fetch arbitrary websites.
  • Unknown record versions and hybrid profiles do not silently receive a verification pass. Pending, unsupported, unavailable, rate-limited, incomplete, and retryable results stay explicit.
  • The connector has no Lens account, original-work upload, payment, credit consumption, evidence creation, or event subscription.

Both tools passed native Claude web testing. The inspection card, report acknowledgement, external Lens link, and complete text or JSON fallback were exercised. This evidence does not claim a full desktop, mobile, or other-host compatibility matrix.

Know how your information is used

The connector receives the public reference in the tool call, retrieves approved public evidence, and returns findings to Claude. Read the privacy policy, terms of use, and support information before using it.
