Connect and check the tools

  1. Install the plugin through an option available to your Claude plan or workspace. If needed, use the public repository’s manual-install instructions.
  2. Open the plugin’s connector settings and connect UCE Evidence Lens. No UCE sign-in or credential is required.
  3. If your workspace supports custom remote connectors, add: https://uce-evidence-lens-claude-zptt2ggs7a-uc.a.run.app/mcp
  4. Confirm that Claude shows exactly inspect_uce_record and get_uce_inspection_report.

Installing the plugin and connecting the remote server are separate steps. The Claude plugin is published, but availability can vary by plan, workspace, host, and listing propagation. As of October 3, 2026, the separate MCP connector’s directory listing is in review and is not live.

Common questions

Claude asks for a reference. Is that expected?
Yes. Supply a public CbyUCE record hash or verification URL, or an Arweave manifest transaction reference, in the current conversation. Each request and report must identify its record.
Why is a check unavailable or retryable?
A public source may be pending, rate limited, unavailable, or too slow. Retry later. An unavailable or retryable result is not evidence of tampering or a mismatch, and it has not passed.
Why is a result partial, reported, or unsupported?
Review which checks completed and their stated coverage. The connector does not infer support for unknown record versions or hybrid profiles. A bundled item’s parent path may remain gateway-reported when Lens has not downloaded and verified the bundle bytes.
What if the reference is rejected?
Use a public CbyUCE verification link or 64-character record hash, or an Arweave manifest transaction link or 43-character ID. Private links, arbitrary websites, pasted manifests, and files are outside the tools’ accepted inputs.
How do I compare my original file?
Use the separate browser-based Evidence Lens and its private local-file comparison. The Claude connector never retrieves or hashes your local original.
What if the interactive card or report download is unavailable?
Claude hosts can still present the complete text result or JSON report fallback. A report remains an unsigned dated inspection, not a UCE Certificate. Saving a downloaded file depends on the host and device.
Can Lens fix or delete a public record?
No. Lens reads public evidence. Contact the record’s publisher or hosting service about corrections or removal; public or permanent records may not be removable.
Does a verified result prove ownership?
No. Review exactly which integrity or chronology check passed and what it covers. Identity, authorship, ownership, rights, consent, provenance, and creation-date statements remain recorded assertions.
